# 음악학원 원생관리 앱

100명 규모 음악학원을 위한 출결·원비·진도 관리 앱입니다. 서버 없이 동작하는 PWA(Progressive Web App)로,
삼성 갤럭시 폰/탭의 브라우저에서 열어 "홈 화면에 추가"하면 일반 앱처럼 설치되어 사용할 수 있습니다.
모든 데이터는 해당 기기의 브라우저(IndexedDB)에 저장되며, 별도 서버나 로그인 없이 오프라인에서도 동작합니다.

## 주요 기능

- **원생 정보 관리**: 사진, 이름, 전화번호, 보호자 전화번호, 학교, 학년, 개인번호(출석용) 관리
- **CSV 일괄 등록**: 초기 100명 등록을 CSV 파일로 한 번에 가져오기 (`sample-students.csv` 참고)
- **출석 체크(키오스크 모드)**: 원생이 자신의 개인번호를 입력 → 확인 화면에서 "출석하기" 터치
  - 출석 시각 자동 기록
  - 등록된 전화번호로 "n월 n일 OOO 학생이 출석하였습니다" 메시지 발송(연동 방식은 아래 참고)
  - 출석 시각 + 1시간 = 하원 가능 시간을 자동 계산, 화면에 실시간 카운트다운 표시
- **원비 관리**: 학생별로 다른 매월 납부일 등록, 완납/미납 체크, 납부일 임박·연체 자동 알림
- **진도 관리**: 학생별 레슨 진도(교재/페이지 등) 이력 기록
- **백업/복원**: 전체 데이터를 JSON 파일로 내보내기/가져오기 (기기 변경, 초기화 대비)

## 문자(SMS) 발송에 대하여

브라우저(클라이언트)에서 알리고/NHN Toast 같은 문자 API를 직접 호출하면 API 키가 노출되어 보안상 위험하므로,
이 앱은 두 가지 방식을 지원합니다.

1. **웹훅 자동 발송(권장)**: 설정 화면에서 웹훅 URL을 등록하면, 출석 처리 시 `{phone, message}` JSON을
   그 주소로 전송합니다. 이 URL은 아래 중 하나로 준비하면 됩니다.
   - 문자 API를 호출하는 간단한 자체 서버(Node.js 등)
   - Make.com, Zapier 같은 자동화 툴의 Webhook → SMS 모듈 연결
   - 학원에서 이미 사용 중인 알림톡/문자 발송 서비스의 Incoming Webhook
2. **수동 발송(웹훅 미설정 시 기본값)**: 출석 처리 시 안드로이드 기본 문자 앱이 메시지 내용과 함께 자동으로
   열립니다. 담당 선생님이 확인 후 전송 버튼만 누르면 됩니다.

## CSV 일괄 등록 형식

`sample-students.csv` 파일을 참고하세요. 컬럼명(헤더)은 한글로 다음을 지원합니다.

| 컬럼 | 필수 | 설명 |
| --- | --- | --- |
| 이름 | 필수 | 원생 이름 |
| 전화번호 | 필수 | 원생 본인 전화번호 |
| 개인번호 | 선택 | 출석 체크용 번호(비우면 자동 부여) |
| 보호자전화번호 | 선택 | 문자 수신 번호(비우면 원생 전화번호로 발송) |
| 학교 / 학년 | 선택 | |
| 납부일 | 선택 | 매월 원비 납부일(1~31) |
| 원비 | 선택 | 월 원비 금액 |
| 메모 | 선택 | |

앱의 "원생 목록 → CSV 일괄등록" 화면에서도 양식 파일을 내려받을 수 있습니다. 초기 등록 후에는
앱 안에서 원생 카드를 눌러 언제든 수정/삭제할 수 있습니다.

## 태블릿/휴대폰 설치 방법

1. 이 앱(정적 파일)을 웹에 호스팅합니다. (예: GitHub Pages, Netlify, Vercel, 또는 사내 웹서버 — HTTPS 필요)
2. 삼성 갤럭시 기기의 삼성 인터넷 또는 크롬 브라우저로 해당 주소를 엽니다.
3. 브라우저 메뉴(⋮) → **"홈 화면에 추가"** 또는 **"앱 설치"** 선택
4. 홈 화면에 생긴 아이콘으로 앱처럼 실행합니다. 이후 인터넷이 없어도 출석/원비/진도 조회·입력이 가능합니다
   (문자 발송, 최초 로딩 제외).

## 로컬에서 미리보기

정적 파일이므로 아무 정적 서버로 실행하면 됩니다.

```bash
cd music-academy
python3 -m http.server 8080
# 브라우저에서 http://localhost:8080 접속
```
